      About FloraVision AI

      The Engineering Challenge

      Classical machine learning projects often rely on static numerical tables (such as Fisher's 1936 4-feature Iris dataset) which lack applicability to real-world photography. FloraVision AI was engineered to bridge this gap: replacing tabular KNN with a genuine convolutional neural network (MobileNetV2) capable of processing real flower photographs.

      Our Approach

      By fine-tuning deep inverted residual bottleneck layers on curated botanical datasets, enforcing a 55% confidence rejection threshold to withhold unconfident predictions, providing Grad-CAM attention heatmaps, and marrying model predictions to verified scientific literature, FloraVision demonstrates how machine learning can serve scientific education without hype or fabricated claims.

      Technology Stack

      • Backend: Python 3.11, Flask, Gunicorn WSGI
      • Deep Learning: PyTorch 2.x, Torchvision (MobileNetV2)
      • Image Processing: Pillow (PIL), NumPy
      • Frontend: Semantic HTML5, Modular CSS3, Vanilla ES6 JavaScript
      • Deployment: Render PaaS (Linux Container, Gunicorn threads)
      • External Dependencies: 0 paid APIs, 0 cloud keys, 0 frontend frameworks
