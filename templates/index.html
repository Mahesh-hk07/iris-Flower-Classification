      Ethical & Responsible AI

      Model Limitations & Boundary Conditions

      Clear documentation of technical constraints, boundary conditions, and responsible usage guidelines.

      🎯

      Five-Class Domain Restriction

      The model is trained solely on Hibiscus, Rose, Sunflower, Lotus, and Iris. It is not a universal botanical classifier. Uploading orchids, lilies, or tulips will trigger rejection or misclassification.

      ⚖️

      Confidence Does Not Equal Certainty

      A high softmax probability represents normalized distance in learned feature space, not infallible biological ground truth. Close visual lookalikes can yield high statistical confidence.

      📸

      Sensitivity to Image Quality

      Harsh shadows, severe overexposure, heavy blur, or excessive background foliage can degrade feature extraction. Close-up, well-lit blossoms yield the most reliable results.

      🏥

      Medical Information Non-Endorsement

      Documented traditional uses are provided strictly for cultural and ethnobotanical education. Traditional use does not establish therapeutic safety or efficacy. Never use this platform as clinical advice.

      Engineering Documentation

      About FloraVision AI

      The Engineering Challenge

      Classical machine learning projects often rely on static numerical tables (such as Fisher's 1936 4-feature Iris dataset) which lack applicability to real-world photography. FloraVision AI was engineered to bridge this gap: replacing tabular KNN with a genuine convolutional neural network (MobileNetV2) capable of processing real flower photographs.

      Our Approach

      By fine-tuning deep inverted residual bottleneck layers on curated botanical datasets, enforcing an empirical 55% out-of-distribution rejection threshold, providing Grad-CAM attention heatmaps, and marrying model predictions to verified scientific literature, FloraVision demonstrates how machine learning can serve scientific education without hype or fabricated claims.

      Technology Stack

      • Backend: Python 3.11, Flask, Gunicorn WSGI
      • Deep Learning: PyTorch 2.x, Torchvision (MobileNetV2)
      • Image Processing: Pillow (PIL), NumPy
      • Frontend: Semantic HTML5, Modular CSS3, Vanilla ES6 JavaScript
      • Deployment: Render PaaS (Linux Container, Gunicorn threads)
      • External Dependencies: 0 paid APIs, 0 cloud keys, 0 frontend frameworks
